Character Export

Log in with your characters through CCP's official EVE login, then download their skills, assets, locations, PI colonies, clones, wallet, industry jobs and market orders as a file. Everything runs in your browser. Nothing is sent anywhere except CCP's own servers.

Your characters

How it works

  1. Add a character. You're sent to CCP's login page, where you sign in and pick a character. Repeat for each character; log out of EVE's site in between if it keeps picking the same one, or use a different account.
  2. Export. The page reads that character's data from CCP's API and saves a .json file to your downloads.
  3. Share it. Attach the file to a chat with Claude, or keep it as a snapshot.

The login is remembered in this browser so you can export again later without signing in. Remove forgets a character here. To fully revoke access, go to EVE's third-party applications page. The file contains your wallet balance and asset list, so only share it with people and tools you trust.
